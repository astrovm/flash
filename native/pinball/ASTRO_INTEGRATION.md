# Astro Pinball integration

The first-party WebAssembly runtime in `site/apps/pinball/runtime` is built from
this source tree. It is based on alula's MIT-licensed Emscripten port of
SpaceCadetPinball at commit `0bc12d3ca97a30a61e1e325cfde1eeec379bb9b9`.
The original MIT license is retained in `LICENSE`.

Astro-specific changes replace the port's dark ImGui presentation with the
Windows XP palette and the Tahoma font extracted from the authenticated XP SP3
ISO. The table, physics, controls, sound, music, high scores, and dialogs remain
native C++/SDL code; the browser shell mounts the canvas directly without an
iframe.

To reproduce the checked-in runtime on macOS:

```bash
brew install emscripten
bun run extract:pinball-assets
bun run build:pinball-runtime
```

The checked-in build was produced with Emscripten 6.0.6. Runtime game assets
are not stored in this source directory. `tools/extract-pinball-assets.ts`
extracts every shipped resource from the XP ISO and records byte-level
provenance in `site/apps/pinball/runtime/SOURCES.json`.

`SpaceCadetPinball/gm_sf2.cpp` embeds the General MIDI bank used by
TinySoundFont for music. It is generated byte-for-byte from the adjacent
`gm.sf2` source file with:

```bash
(cd native/pinball/SpaceCadetPinball && xxd -i gm.sf2 > gm_sf2.cpp)
```
