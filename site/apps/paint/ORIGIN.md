# Paint origin and license

This application began with the browser runtime from
[1j01/jspaint](https://github.com/1j01/jspaint), pinned to commit
`53be67ab8c47cc0d2168899e7481bc04839c4c81` (version 1.1.0).

It is now maintained as Astro Flash's first-party Windows XP Paint
implementation. We do not track upstream compatibility; the code may be
reorganized, reduced, and changed to match Windows XP behavior directly.
